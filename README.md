# MicroMentor - Full Stack Mentorship Platform


MicroMentor is a full-stack mentorship management platform designed to connect mentors and learners through a secure and scalable web application.

The platform provides user authentication, mentor management, and REST API-based communication between frontend and backend systems.


---
